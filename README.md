# Houdini Craft Index

A living, short list of **current** Houdini craft resources — docs, learning, tools, and community that still matter for Houdini craft \(Solaris / Karma / Copernicus, modern SOPs, VEX — version-agnostic, current practice\).

Maintained by Matt Peterson ([cgpetey](https://github.com/cgpetey)). Not an exhaustive awesome-list: if it is not useful this year, it does not belong here.

> Inspired by [agmmnn/houdini-resources](https://github.com/agmmnn/houdini-resources); aggressively curated for current practice. Last curated: 2026-09-12 (added Junichiro Horikawa).

## Curation rules

1. **Current craft only** — H22-era or still best practice. Live URLs that are museum pieces get cut.
2. **Short over complete** — prefer deleting to accumulating.
3. **No Gumroad one-offs, FB groups, or third-party renderer marketing** unless they become core craft docs.
4. Re-audit periodically.
